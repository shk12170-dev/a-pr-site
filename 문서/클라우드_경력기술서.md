# 경력기술서 — 김상혁 (클라우드 엔지니어 지원)

과제마다 세 가지 능력 중 어디에 해당하는지와 상황·행동·결과를 적었습니다.

## 1번 — 공개 소개 페이지

- **해당 능력**: 자기동기력
- **상황**: 처음 온 사람이 계정 없이 볼 수 있는 소개 페이지가 필요했다.
- **행동**: 정적 HTML로 소개 페이지를 만들고 GitHub Pages에 배포했다.
- **결과**: 로그인 없이 열리는 공개 페이지를 확보했고, 이후 8번 과제의 공개 첫 화면으로 재사용했다.
- **확인**: https://shk12170-dev.github.io/portfolio/ (로그인 없이 열림)

## 4번 — 환율 조회 페이지

- **해당 능력**: 자기동기력
- **상황**: 외부에서 오는 데이터를 화면에 붙여야 했다.
- **행동**: 공개 환율 데이터를 가져와 화면에 연결하고, 확인 방법과 검증 보고서를 따로 작성했다.
- **결과**: 로그인 없이 열리는 공개 페이지와 점검 문서를 함께 남겼다.
- **확인**: https://shk12170-dev.github.io/exchange-rate/ (로그인 없이 열림)

## 5번 — 프로젝트 인계 (HANDOVER)

- **해당 능력**: 대인관계력
- **상황**: 만든 사람이 아니어도 이어서 작업할 수 있어야 했다.
- **행동**: 인계 문서(HANDOVER)와 테스트 목록(TESTS)을 작성해 무엇이 끝났고 무엇이 남았는지 분리했다.
- **결과**: 다른 사람이 읽고 이어받을 수 있는 형태로 넘겼고, 이후 과제의 README 작성 방식의 기준이 되었다.

## 8번 — 패스키 포트폴리오 (비밀번호 없는 인증)

- **해당 능력**: 자기조절력
- **상황**: 비밀번호를 서버에 두지 않고 비공개 영역을 열어야 했다.
- **행동**: 공개키·credential ID·sign counter만 저장하는 구조를 택하고, CSRF 토큰 검증·challenge 재사용 차단·마지막 패스키 삭제 금지를 직접 결정했다. 배포된 서버에 실제 요청을 보내 응답을 증거 문서로 자동 생성하는 스크립트를 만들고, 긴 무작위 값은 자동으로 가렸다.
- **결과**: 비밀번호와 개인키를 저장하지 않는 인증을 배포하고, 6개 확인 항목을 실제 응답으로 증명한 문서를 함께 남겼다.
- **확인**: https://passkey-portfolio.vercel.app (로그인 없이 열림)

## 9번 — 리추얼 기록에서 강점 찾기

- **해당 능력**: 대인관계력
- **상황**: "책임감이 있다" 같은 주장 대신 근거로 강점을 말해야 했다.
- **행동**: 기록에 적힌 구체적 행동만 근거로 쓰고 반복되는 패턴만 인정하는 규칙 5개를 정했다. 그 규칙에 따라 근거가 2회뿐인 후보는 스스로 제외했고, 완성한 서사를 동료 두 명에게 "나 같은가, 지어낸 느낌이 있는가"로 검증받았다.
- **결과**: 날짜와 원문이 붙은 강점 지도와 1인칭 서사를 만들었고, 두 사람 모두 과장이 없다고 답했다.
- **확인**: https://agent-ritual.vercel.app (로그인 없이 열림)

## 10번 — 논문 — CNCF 프로젝트의 기여자 수와 이슈 처리 시간

- **해당 능력**: 자기동기력
- **상황**: 가설 검증에 필요한 자료를 대시보드에서 손으로 받으려면 100회가 넘는 반복 작업이 필요했다.
- **행동**: 같은 지표를 공개 API로 자동 수집하는 스크립트로 설계를 바꿔 10개 프로젝트 × 12개월 = 120행을 모았다. 결과가 가설과 반대로 나온 뒤에는 로그 변환·극단값 제외·프로젝트 평균 비교까지 세 방식으로 다시 확인했다.
- **결과**: 가설을 끼워 맞추지 않고 그대로 기각하고, 왜 반대로 나왔는지를 선행 연구 4편을 근거로 적었다. 원자료와 수집·분석 스크립트를 함께 공개해 다시 돌릴 수 있게 했다.

## 11번 — 장편 원고 『갇힌 방에서 나가는 법』

- **해당 능력**: 자기조절력
- **상황**: 9번 과제에서 몇 문단으로 줄여 적었던 회복 과정을 온전한 크기로 풀어야 했다.
- **행동**: 리추얼 기록의 날짜와 문장을 기준으로 10장을 구성하고, 인물·관계·지명·시간선 대조표를 만들어 본문과 맞춰봤다. 그 과정에서 시간선이 어긋난 곳과 같은 내용이 두 번 반복된 곳을 찾아 3건을 고쳤다.
- **결과**: 공백 제외 30,056자 원고와 대조표, 수정 기록을 남겼다. 지어낸 장면을 넣지 않는다는 기준을 문서로 명시했다.
