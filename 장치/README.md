# 계속 새로 쓰는 장치

리추얼 기록·과제 목록·출석 파일을 읽어 **두 사이트(`site-backend/`, `site-cloud/`)를 다시 만드는** 프로그램입니다.
새 기록을 넣고 한 번 돌리면 사이트의 숫자 칸과 능력별 문단이 갱신됩니다.

## 돌리는 방법 (3단계)

1. **입력 파일을 넣는다** — 과제 화면의 「JSON으로 담기」로 받은 파일을 `입력/리추얼기록.json` 이름으로 저장합니다. 출석 숫자는 `입력/출석.json`에 적습니다.
2. **실행한다** — 이 폴더에서 아래 명령을 실행합니다.
   ```
   python build.py
   ```
3. **결과를 확인한다** — `site-backend/index.html`, `site-cloud/index.html`이 다시 만들어지고, `마지막결과/숫자.json`과 `마지막결과/문단후보.md`가 갱신됩니다. 브라우저에서 두 index.html을 열어 확인합니다.

필요한 것은 **Python 3.9 이상뿐**입니다. 설치할 외부 패키지가 없습니다(표준 라이브러리만 사용).

## 같은 입력이면 같은 결과가 나오는 이유

- 실행 중에 **AI를 호출하지 않습니다.** 필요한 API 키나 환경 변수가 없습니다.
- 사이트에 들어가는 문장은 `승인문장/능력별_장면.json`에서 `"승인": true`인 것만 읽습니다. 사람이 승인한 문장만 나갑니다.
- 숫자는 `입력/` 폴더의 파일에서만 셉니다.
- 결과물에 **실행 시각을 넣지 않습니다.** 기간 표시는 기록 파일 안의 날짜에서 가져옵니다.

확인하려면 두 번 실행한 뒤 결과 파일을 비교하면 됩니다.

```
python build.py
md5sum ../site-backend/index.html ../site-cloud/index.html
python build.py
md5sum ../site-backend/index.html ../site-cloud/index.html
```

두 번의 md5 값이 같아야 합니다. (Windows PowerShell에서는 `Get-FileHash`)

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `build.py` | 실행 파일 |
| `입력/리추얼기록.json` | 아침·마무리 기록 (과제 화면에서 받음) |
| `입력/리추얼기록.예시.json` | 기대하는 입력 형식 예시 |
| `입력/과제목록.json` | 과제별 상황·행동·결과·능력 |
| `입력/출석.json` | 출석 숫자 |
| `입력/검증숫자.json` | 다시 셀 필요 없는 확정 숫자(출처 포함) |
| `승인문장/능력별_장면.json` | 사이트에 나갈 인용문. 승인되지 않은 문장은 나가지 않음 |
| `템플릿/site.html.tmpl` | 사이트 틀 |
| `마지막결과/` | 마지막 실행 결과 (숫자.json, 문단후보.md) |

## 입력 형식

`리추얼기록.json`은 날짜·아침·마무리 칸이 있는 기록 목록이면 됩니다. 아침·마무리 값은 문자열이어도 되고, 화면처럼 여러 칸으로 나뉜 객체여도 읽습니다. 자세한 형태는 `입력/리추얼기록.예시.json`을 보세요.

입력 파일이 없으면 그 숫자 줄만 빠진 채로 사이트가 만들어지고, 실행할 때 어떤 파일이 없는지 알려줍니다.

## 새 폴더에서 처음부터 돌려보기

```
git clone <이 저장소 주소> 새폴더
cd 새폴더/장치
python build.py
```

입력 폴더의 파일들이 함께 들어 있으므로 바로 같은 결과가 나옵니다.
