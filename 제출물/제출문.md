## AI와 나의 판단

1. **AI에게 맡긴 일**
   - 1~11번 과제 결과물이 흩어져 있던 GitHub 저장소를 찾아 과제 번호와 대조하고 재료 맵으로 정리한 일
   - 3만 자 소설에서 고난·회복·지금 흐름과 세 능력에 해당하는 장면을 추려 자기소개 본문 초안을 쓴 일
   - 사이트 템플릿과 장치(build.py) 구현, 이력서·자기소개서·경력기술서 6개 문서 생성
   - 공개 URL이 로그인 없이 열리는지 확인하고, 제출물에 타인 실명·비밀값이 있는지 검사한 일

2. **내가 직접 판단한 일**
   - 12번 SOAR 알림 과제는 실습 과제이므로 이번 재료에서 빼기로 한 것
   - 지원 목표를 백엔드 개발자와 클라우드 엔지니어 두 갈래로 정한 것
   - 사이트를 하나로 합치지 않고 목표별로 두 개로 나누기로 한 것
   - GitHub 업로드와 Vercel 배포를 직접 수행하기로 한 것
   - 사이트에 쓸 문장은 리추얼 기록 원문으로 확인되는 것만 쓰고, 소설에서 각색된 대화·묘사는 넣지 않기로 한 것

3. **AI 제안을 따르지 않은 일**
   - AI는 제출 URL이 한 개여야 한다는 이유로 사이트를 하나만 만들고 그 안에서 두 트랙을 고르게 하자고 제안했다. 목표가 다르면 첫 화면부터 달라야 한다고 판단해 따르지 않고 사이트를 두 개로 나눴다. 대신 제출 필드에는 한 개만 넣고 나머지 하나는 첫 화면 링크로 연결하는 방식으로 제출 규칙을 맞췄다.

## 완주 확인

- 소설에서 뽑은 자기소개 본문이 사이트 가운데에 있고, 각색된 대화·묘사는 넣지 않았습니다.
- 첫 화면에 이름과 “…한 사람”으로 끝나는 한 줄 소개가 있고, 그 안에 날짜가 있습니다.
- 숫자 칸 5개에 모두 출처를 적었습니다.
- 대표작 자리에 10번 논문 파일을 직접 올렸고, 13번 앱 자리를 비워 두었습니다.
- 과제 11개를 이력서·경력기술서에 능력별로 나눠 적었습니다.
- 장치를 두 번 돌리고 새 폴더에서도 돌려 결과가 같은 것을 확인했습니다.
- 제출물에 본인 이름과 공개하기로 한 연락 수단 외의 개인정보, 비밀번호·토큰·API 키는 없습니다.
