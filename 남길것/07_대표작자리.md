# 07. 대표작 자리 (논문, 앱 예정)

## 8번 과제 — 패스키 포트폴리오 (WebAuthn)

- 상태: 공개
- 설명: 비밀번호를 서버에 두지 않고 패스키로만 열리는 비공개 영역. 공개키·credential ID·sign counter만 저장하고, CSRF 토큰 검증·challenge 재사용 차단·마지막 패스키 삭제 금지를 직접 설계했습니다.
- 링크: https://passkey-portfolio.vercel.app

## 10번 과제 — 논문 — CNCF 프로젝트의 기여자 수와 이슈 처리 시간

- 상태: 공개
- 설명: 공개 데이터로 가설을 세우고 검증했습니다. GitHub REST API로 10개 프로젝트 × 12개월 = 120행을 수집해 분석했고, 가설과 반대 결과가 나온 것을 그대로 기각으로 적었습니다.
- 링크: https://a-pr-site.vercel.app/자료/논문.docx (사이트에 파일을 직접 올려 로그인 없이 열림)
